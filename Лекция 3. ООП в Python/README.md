# Лекция 3. Объектно-ориентированное программирование в Python

Сторонние библиотеки не требуются. Команды выполняются из папки лекции.
Флаг `-i` запускает файл и оставляет интерактивную консоль, в которой
можно создавать объекты и вызывать их методы. Чтобы выйти, введите `exit()`.

## Задачи со слайдов 11, 19, 27 и 31

| Файл | Что реализовано |
| --- | --- |
| `1.py` | `Book(title, author, year)` хранит данные о книге. `info()` возвращает описание. |
| `2.py` | `Ebook` наследует `Book` из первой задачи, хранит формат и переопределяет `info()`. |
| `3.py` | Книга поддерживает `str()`, сравнение по трём полям, чтение и изменение `age` и создание через `Book.from_string("название;автор;год")`. Присваивание возраста пересчитывает год издания. |
| `4.py` | Абстрактный класс `Printable` задаёт интерфейс `print_info()`. `Book` печатает результат `info()`, поэтому унаследованный метод печатает и формат электронной книги. |

Чтобы проверить итоговую версию, запустите `python -i 4.py` и введите:

```python
book = Ebook.from_string("Пикник на обочине;Аркадий и Борис Стругацкие;1972;EPUB")
book.print_info()
print(book.age)
```

### № 3. Онлайн-магазин

`ShoppingCart` резервирует товар при добавлении и возвращает его на склад
при удалении или уменьшении количества. Нулевое количество удаляет позицию.
`Customer.checkout()` создаёт `Order`, сохраняет его в истории покупателя
и очищает корзину. Скидка задаётся долей от стоимости, а налог в 10% по
умолчанию начисляется на сумму после скидки.

Пример для `python -i p3.py`:

```python
product = Product("Набор карандашей", 200, 5, "Канцелярия")
cart = ShoppingCart()
cart.add_product(product, 2)
cart.update_quantity(product, 3)
customer = Customer("Анна", "anna@example.com")
print(customer.checkout(cart, discount=0.1))
print(customer.order_history[0].total_price)  # 594.0
```

### № 4. Симулятор космического корабля

`SpaceShip` расходует топливо на манёвры и теряет прочность корпуса при
столкновении. `CrewMember` учитывает здоровье и роль члена экипажа:
инженер ремонтирует корпус с учётом уровня навыка, пилот сообщает об уклонении.
`Mission` хранит цель, корабль и экипаж. Случайное событие может вызвать
утечку топлива, столкновение с астероидом или пройти без происшествий.

Пример для `python -i p4.py`:

```python
ship = SpaceShip("Заря", fuel=80, hull=100)
crew = [CrewMember("Анна", "пилот", 4), CrewMember("Иван", "инженер", 5)]
mission = Mission("Луна", ship, crew)
ship.change_speed(20)
mission.trigger_random_event()
```
