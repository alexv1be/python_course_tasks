# Лекция 4.1. Шаблоны Django

Проект `library` содержит каталог книг, страницу с фотографиями собак и две
консольные программы. Команды ниже выполняются в PowerShell из корня репозитория.

## Запуск Django

Проект проверен в существующем окружении `.venv` с Python 3.14. Если окружение
нужно создать заново, выполните `py -3.14 -m venv .venv` из корня репозитория.

```powershell
Set-Location Lecture_4_Django/library
$python = '../../.venv/Scripts/python.exe'
& $python -m pip install -r requirements.txt
& $python manage.py migrate
& $python manage.py runserver
```

### Задачи № 2 и № 3. Каталог библиотеки

Откройте `http://127.0.0.1:8000/` для просмотра списка книг. Каждая книга
открывается по адресу `/books/<id>/`. Если книги с указанным ID нет, Django
возвращает HTTP 404.

Каталог изначально пуст. Для добавления книги выполните в той же папке
`& $python manage.py createsuperuser`, войдите в `http://127.0.0.1:8000/admin/`
и добавьте запись **Book** с названием, автором и описанием.

`library/settings.py` задаёт папки шаблонов и статики. `catalog/urls.py`
связывает маршруты с функциями в `catalog/views.py`. Модель `Book`
хранит записи в SQLite. Представление `book_detail` передаёт найденную книгу
в контексте `book_detail.html`. Страницы наследуют общий шаблон `base.html`
и подключают CSS через тег `static`.

### Практика № 1. Карточка покемона

```powershell
& $python pokemon_lookup.py
```

Программа загружает первые 20 имён, а затем запрашивает карточку по имени,
введённому через `input()`. Например, введите `clefairy`. Рост и вес выводятся
в метрах и килограммах, а типы и способности перечисляются через запятую.

### Практика № 2. Фотографии собак

Откройте `http://127.0.0.1:8000/dogs/` при запущенном сервере. Страница
показывает нумерованный список пород и подпород. Введите, например,
`african, chow, dingo` и нажмите **Показать фотографии**. Для подпороды
используйте формат `breed/subbreed`, например `hound/afghan`.

`catalog/dog_api.py` получает список у Dog API, кеширует его на час и запрашивает
по одному случайному фото для каждой выбранной породы. Django передаёт список,
фото и сообщения об ошибках в шаблон `dog_gallery.html`.

### Практика № 3. Менеджер команды покемонов

```powershell
& $python pokemon_team.py
```

Через меню можно добавить покемона, удалить его, просмотреть карточки всей
команды, найти покемона по имени и провести тренировочный бой. Например,
добавьте `pikachu` и `clefairy`, выберите пункт 5 и введите их имена.
Повторное добавление не создаёт дубликат. Команда хранится до выхода из программы.

Для учебного боя складываются базовые характеристики каждого участника
из PokéAPI. Побеждает покемон с большей суммой, а при равенстве объявляется ничья.

Практики с API требуют интернет. `api_http.py` выполняет GET-запросы с тайм-аутом,
а `pokemon_api.py` получает и форматирует карточки для двух консольных программ.
Описание ответов доступно в документации [PokéAPI](https://pokeapi.co/docs/v2)
и [Dog API](https://dog.ceo/dog-api/documentation/).
